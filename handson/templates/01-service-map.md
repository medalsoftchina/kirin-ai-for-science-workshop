# 演習① サービスマップ — Azure サービスマップ

**目的:** ご自身の研究テーマのデータフロー（どんなデータを、どこに保管し、どう検索・分析し、どう統制するか）に、今日体験した Azure サービスを対応付け、導入の優先順位を付けます。

**記入のしかた（目安 15 分）:**

1. ご自身の研究テーマを 1 つ選んでください（例: 乳酸菌の機能性解析、メタゲノム解析、ゲノム変異と表現型の関連解析 など）。
2. その研究のプロセスを思い浮かべ、1 行ずつ表に記入してください。最初の 2 行は記入例です。
3. 「対応 Azure サービス」は今日触れたもの（AI Search / Foundry IQ / Foundry Agent Service など）に限らず、Day 1 で学んだサービスを挙げても構いません。
4. すべての行を埋められなくても大丈夫です。**導入優先度「高」が 1 つでも付けば十分です。**
