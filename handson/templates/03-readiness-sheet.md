# 演習③ R&D AI Readiness Sheet

**目的:** 自組織が研究 AI（RAG・エージェント）を導入・運用するための準備度を、6 つの軸で自己評価します。スコアの絶対値よりも、**半年後の目標とのギャップ**が重要です。そのギャップが「改善・検証バックログ」の種になります。

**記入のしかた:** 各軸について現状を 1〜5 で自己採点し（1 = これから着手 〜 5 = 運用が回っている）、採点の根拠をメモしてください。お持ち帰りいただき、部内で議論しながら完成させる形で構いません。

## Part A: 6 軸の自己評価

| # | 評価軸 | 問い（評価の視点） | 現状スコア (1–5) | 根拠メモ |
|---|---|---|---|---|
| 1 | **組織・ガバナンス** | AI 利用の方針・承認プロセスは整っているか。責任の所在は明確か | | |
| 2 | **データ基盤** | 研究データは整理・管理され、AI から参照できる形になっているか | | |
| 3 | **人材・スキル** | ツールを使いこなし、出力を検証できる人材はいるか | | |
| 4 | **セキュリティ・権限** | アクセス制御・データ境界（個人情報・機密データの扱い）は確立しているか | | |
| 5 | **運用・モニタリング** | コスト管理・品質監視・継続的改善の仕組みはあるか | | |
| 6 | **ユースケースの成熟度** | 導入したいユースケースは具体的で、成功指標が定義されているか | | |

## Part B: バックログへの接続

ギャップの大きかった軸（スコアの低い軸、または半年後に伸ばしたい軸）について、具体的なアクションを **[04-backlog.md（改善・検証バックログ）](04-backlog.md)** に落としてください。検証（試して確かめる）・改善（仕組みを直す）・調査（情報を集める）の 3 種別で整理します。
